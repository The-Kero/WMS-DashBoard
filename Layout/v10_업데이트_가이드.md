#### 📄 **2.3. 100인치 TV 스펙 및 제약사항**

**위치**: `Phase2_진척도.md` Day 6 섹션

**하드웨어 제약**:
```
해상도:    1920 × 1080 픽셀
시청거리:  10m (작업자 위치)
조명:      창고 조명 (밝음, 색상 대비 중요)
운영:      24/7 무인 운영
상호작용:  없음 (클릭, 호버 불가)
```

**폰트 크기 제약** (10m 거리 가독성):
```
최소 크기:
- 제목/헤더:     48px 이상
- 카드 타이틀:   32px 이상
- 숫자(값):      72px 이상
- 단위:          28px 이상
- 서브텍스트:    24px 이상
- 테이블 셀:     20px 이상

⚠️ 이보다 작으면 10m에서 안 보임!
```

**색상 대비 요구사항**:
```
최소 대비율: 5:1 (WCAG AA 기준)

권장 조합:
- 배경(#1a1a1a) + 텍스트(#ffffff) → 대비율 15:1 ✅
- 긴급(#FF4444) + 배경(#ffffff) → 대비율 4.5:1 ⚠️
- 주의(#FF8800) + 배경(#ffffff) → 대비율 3.2:1 ❌

→ 긴급/주의는 진한 배경 필수!
```

**카드 개수 제한**:
```
화면 공간: 1920 × 1080 = 2,073,600 픽셀

권장 카드 개수:
- 최소: 4개 (너무 적음, 정보 부족)
- 권장: 6~10개 (균형)
- 최대: 12개 (이상 시 글자 작아짐)

카드 1개 평균 크기:
- 6개: 약 460×360 픽셀 (여유)
- 8개: 약 460×270 픽셀 (적정)
- 10개: 약 370×270 픽셀 (최소)
- 12개: 약 370×216 픽셀 (한계)

⚠️ 12개 초과 시 10m 거리 가독성 저하!
```

**레이아웃 제약**:
```
그리드 시스템:
- 2 × 3 = 6개  ✅ 권장
- 3 × 3 = 9개  ✅ 권장
- 4 × 3 = 12개 ✅ 최대
- 5 × 3 = 15개 ❌ 비권장 (글자 작음)

여백:
- 카드 간 갭: 최소 20px
- 외곽 여백: 최소 30px
```

## 10. FAQ

### Q1. v10 파일은 어디에 저장하나요?

```
A: C:\Projects\WMS-DashBoard\Layout\v10.html
   C:\Projects\WMS-DashBoard\Layout\v10_설계서.md
   
   이 폴더에 모두 저장하면 Claude가 바로 읽을 수 있습니다.
```

### Q2. API 수정이 꼭 필요한가요?

```
A: 케이스별로 다릅니다.
   • 현재 API 데이터만 사용 → 수정 불필요
   • 백엔드 CSV의 다른 컬럼 필요 → 수정 필요 (30분~1시간)
   • 새로운 계산 로직 필요 → 수정 필요 (1~2시간)
   
   v10 설계서 작성하면서 판단하시면 됩니다.
```

### Q3. 카드는 몇 개가 적당한가요?

```
A: 권장 6~10개
   • 6-8개: 가독성 우수, 정보량 적음
   • 9-10개: 균형적
   • 11-12개: 최대치, 글자 작아짐
   • 13개 이상: 비권장 (10m 거리 가독성 저하)
```

### Q4. v9를 완전히 버리고 새로 만드나요?

```
A: 아니요!
   v9는 기본 틀입니다. v10은 v9를 확장/개선한 버전입니다.
   
   v9 → v10 관계:
   • v9 카드 구조 유지
   • 카드 개수 증가 (6개 → 8~10개)
   • 같은 데이터를 더 세분화
   • 필요시 API 확장
```

### Q5. Day 4 전에 v10을 꼭 완성해야 하나요?

```
A: 네, 필수입니다!
   v10이 Day 4의 "설계도"입니다.
   
   v10 없으면:
   • Claude가 무엇을 만들지 모름
   • 시행착오 반복
   • 재작업 발생
   • 시간 2배 소요
   
   v10 있으면:
   • 명확한 목표
   • 체크리스트처럼 진행
   • 재작업 없음
   • 시간 절반
```

### Q6. v10 설계서는 얼마나 자세하게 써야 하나요?

```
A: 템플릿 정도면 충분합니다.
   
   필수 항목:
   • 카드 개수 및 배치
   • 각 카드별 데이터 소스
   • 표시 내용 (큰 숫자, 서브텍스트)
   • 데이터 매핑표
   
   선택 항목:
   • 색상 체계
   • 특수 효과
   • 주의사항
```
