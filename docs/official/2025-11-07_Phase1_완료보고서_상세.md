### 1. BaseCollector 패턴 구현

**설계 철학**:
```python
class BaseCollector(ABC):
    """모든 Collector의 추상 베이스 클래스"""
    
    @abstractmethod
    def load_data(self) -> pd.DataFrame:
        """CSV 파일 로드"""
        
    @abstractmethod
    def collect(self) -> Dict[str, Any]:
        """핵심 지표 수집"""
        
    @abstractmethod
    def validate(self) -> bool:
        """데이터 검증"""
        
    @abstractmethod
    def get_metrics(self) -> Dict[str, float]:
        """메트릭 반환"""
```

**장점**:
- ✅ **일관성**: 모든 Collector 동일 인터페이스
- ✅ **확장성**: 새 Collector 추가 용이
- ✅ **재사용성**: Flask API 100% 재사용 가능
- ✅ **테스트 용이성**: 공통 테스트 패턴
