### JSON 값 참고 범위 (판단 아님!)
```
⚠️ 주의: 이 범위는 참고용일 뿐, AI가 판단하지 않음!

일반적인 값 (참고만):
- progressRate: 0~100
- amount: 0 이상 (음수 아님)
```

### ⚠️ 카드6 특별 규칙 (중요!)
```
🚨 미발행 피킹리스트 계산 규칙 (절대 잊지 말 것!)

❌ 잘못된 계산:
   피킹 리스트 == 'N' 인 모든 건수

✅ 올바른 계산:
   피킹 리스트 == 'N' AND 오더수량* > 0
   
이유:
- 오더수량이 0이면 피킹할 물량이 없음
- 피킹리스트를 안 뽑는게 정상
- 미발행 건수에 포함하면 안 됨

코드:
card6_unpublished_picking = len(
    card6_data[
        (card6_data['피킹 리스트'] == 'N') & 
        (card6_data['오더수량*'] > 0)
    ]
)

⚠️ 케로님이 이미 3번 설명하신 규칙입니다!
   절대 잊지 말고 항상 확인하세요!
```
