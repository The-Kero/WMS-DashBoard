# WMS 백엔드 스케줄러 관리 가이드

> 작성일: 2025-11-26  
> 용도: 5개 핵심 모듈 자동 실행 스케줄러 관리

---

## 1. 개요

### 1.1 목적
OSIS 서버에서 데이터를 주기적으로 수집하여 CSV 파일로 저장

### 1.2 등록된 스케줄러

| 작업 이름 | 대상 모듈 | 출력 파일 |
|----------|----------|----------|
| WMS_Inbound_Collector | 입고현황 | integrated_inbound_{날짜}.csv |
| WMS_Outbound_Collector | 출고현황 | outbound_all_{날짜}.csv |
| WMS_Inventory_Collector | 재고현황 | inventory_status_{날짜}.csv |
| WMS_Delete_Collector | 삭제현황 | delete_status_{날짜}.csv |
| WMS_Irregular_Collector | 비정형오더 | irregular_order_{날짜}.csv |

### 1.3 운영 조건

| 항목 | 설정값 |
|------|--------|
| 운영 요일 | 일, 월, 화, 수, 목, 금 (토요일 제외) |
| 시작 시간 | 09:00 |
| 종료 시간 | 24:00 (15시간 동안 실행) |
| 실행 간격 | 5분마다 |

| 파일명 | 역할 |
|--------|------|
| run_inbound.vbs | 입고현황 실행 |
| run_outbound.vbs | 출고현황 실행 |
| run_inventory.vbs | 재고현황 실행 |

위치: `C:\OSIS_AUTO\`

| 파일명 | 용도 |

| scheduler_irregular.xml | 비정형오더 스케줄러 설정 |

각 모듈 폴더에 저장됨

| 모듈 | 로그 파일 경로 |
|------|---------------|

| 재고현황 | C:\OSIS_AUTO\inventory_status\inventory.log |

## 3. 관리 명령어

### 3.1 상태 확인
```powershell
# 전체 WMS 스케줄러 상태 확인
Get-ScheduledTask | Where-Object {$_.TaskName -like "WMS_*"} | Format-Table TaskName, State

# 다음 실행 시간 확인
Get-ScheduledTask | Where-Object {$_.TaskName -like "WMS_*"} | ForEach-Object {
    $info = Get-ScheduledTaskInfo -TaskName $_.TaskName
    Write-Host "$($_.TaskName): $($info.NextRunTime)"
}
```

### 3.2 ON/OFF 제어
```powershell
# 특정 스케줄러 끄기 (비활성화)
Disable-ScheduledTask -TaskName "WMS_Inbound_Collector"

# 특정 스케줄러 켜기 (활성화)
Enable-ScheduledTask -TaskName "WMS_Inbound_Collector"

# 전체 WMS 스케줄러 끄기
Get-ScheduledTask | Where-Object {$_.TaskName -like "WMS_*"} | Disable-ScheduledTask

# 전체 WMS 스케줄러 켜기
Get-ScheduledTask | Where-Object {$_.TaskName -like "WMS_*"} | Enable-ScheduledTask
```

### 3.3 즉시 실행 (테스트용)
```powershell
# 특정 스케줄러 즉시 실행
Start-ScheduledTask -TaskName "WMS_Inbound_Collector"
```

### 3.4 삭제
```powershell
# 특정 스케줄러 삭제
Unregister-ScheduledTask -TaskName "WMS_Inbound_Collector" -Confirm:$false

# 전체 WMS 스케줄러 삭제
Get-ScheduledTask | Where-Object {$_.TaskName -like "WMS_*"} | Unregister-ScheduledTask -Confirm:$false
```

### 3.5 재등록 (설정 변경 후)
```powershell
schtasks /create /tn "WMS_Inbound_Collector" /xml "C:\OSIS_AUTO\scheduler_inbound.xml" /f
```

## 4. 문제 해결

### 4.1 스케줄러가 실행 안 됨

**확인 순서**:
1. 상태 확인: `Get-ScheduledTask -TaskName "WMS_*"`
2. State가 "Disabled"면 → `Enable-ScheduledTask` 실행
3. State가 "Ready"인데 안 돌면 → 다음 실행 시간 확인

### 4.2 CSV 파일이 갱신 안 됨

**확인 순서**:
1. 로그 파일 확인 (에러 메시지 확인)
2. VBS 파일 직접 실행 테스트:
   ```
   더블클릭: C:\OSIS_AUTO\scripts\run_inbound.vbs
   ```
3. Python 스크립트 직접 실행 테스트:
   ```
   python "C:\OSIS_AUTO\Inbound Status\inbound_status.py"
   ```

### 4.3 로그 파일이 없음

**원인**: 스케줄러가 한 번도 실행 안 됨
**해결**: 즉시 실행으로 테스트
```powershell
Start-ScheduledTask -TaskName "WMS_Inbound_Collector"
```

### 4.4 로그에 에러 메시지

**흔한 에러**:
| 에러 | 원인 | 해결 |
|------|------|------|
| ModuleNotFoundError | Python 패키지 없음 | pip install 실행 |
| ConnectionError | OSIS 서버 접속 불가 | 네트워크 확인 |
| FileNotFoundError | 경로 오류 | 스크립트 경로 확인 |

### 4.5 24시 이후에도 실행됨

**원인**: Duration 설정 오류
**해결**: XML 파일에서 `<Duration>PT15H</Duration>` 확인

## 5. GUI로 관리하기

### 5.1 작업 스케줄러 열기
```
Win + R → taskschd.msc → Enter
```

### 5.2 WMS 작업 찾기
- 왼쪽 패널: "작업 스케줄러 라이브러리" 클릭
- 이름 열에서 "WMS_" 로 시작하는 작업 찾기

### 5.3 GUI에서 ON/OFF
- 작업 우클릭 → "사용 안 함" (OFF)
- 작업 우클릭 → "사용" (ON)

### 5.4 GUI에서 설정 변경
- 작업 더블클릭 → 속성 창
- "트리거" 탭: 시간, 반복 간격 변경
- "동작" 탭: 실행 파일 변경

## 7. 참고 사항

### 7.1 출고현황 소요 시간
- 첫 실행 (콜드 스타트): 60~80초
- 이후 실행 (웜 스타트): 4~10초
- 5분 간격이면 충분히 여유 있음

### 7.2 로그 파일 관리
- 현재: 매 실행 시 덮어쓰기 (최신 1회분만 유지)
- 필요시 VBS 수정하여 날짜별 로그 가능

### 7.3 PC 재시작 후
- 스케줄러 자동 복구됨 (Windows Task Scheduler가 관리)
- 별도 조치 불필요
