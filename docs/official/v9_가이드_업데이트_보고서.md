**4가지 증상과 해결책:**
1. **용인2/용인3 수량 이상**
   - 원인: 배송처명만으로 분류
   - 해결: 배송군 확인 필수

2. **한익스/키즈가 0으로 나옴**
   - 원인: 05타입 특수 규칙 미적용
   - 해결: 배송처명=='식재', 배송군[0]=='3' 확인

3. **양산/양산2 구분 안 됨**
   - 원인: '양산'이 '양산2'에 포함됨
   - 해결: 정확한 문자열 비교 (== 사용)

4. **모든 배송처가 0으로 나옴**
   - 원인: classify 함수 미적용
   - 해결: apply() + groupby() + 매핑
