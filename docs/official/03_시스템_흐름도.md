## 📊 데이터 수집 흐름

### 전체 수집 프로세스

```mermaid
flowchart TD
    Start([프로그램 시작]) --> Login[1. OSIS 로그인]
    Login --> GetCookie[2. 세션 쿠키 획득<br/>JSESSIONID, AWSALB, AWSALBCORS]
    GetCookie --> UpdatePacket[3. 요청 패킷에<br/>쿠키 삽입]
    UpdatePacket --> SendRequest[4. 데이터 조회 요청<br/>HTTP POST]
    SendRequest --> ReceiveXML[5. XML 응답 수신]
    ReceiveXML --> ParseXML[6. XML 파싱<br/>lxml]
    ParseXML --> ProcessData[7. 데이터 처리<br/>pandas DataFrame]
    ProcessData --> CheckChange{8. 변화 감지<br/>SHA256}
    
    CheckChange -->|변화 있음| Backup[9a. 기존 파일 백업]
    CheckChange -->|변화 없음| Skip[9b. 저장 생략]
    
    Backup --> SaveCSV[10. CSV 저장<br/>UTF-8 BOM]
    SaveCSV --> End([완료])
    Skip --> End
```

---

### 공통 처리 단계

**모든 모듈이 공유하는 5단계 프로세스:**


```
┌────────────────────────────────────────────────────────────────┐
│ 1단계: 인증 (Authentication)                                   │
│    - OSIS 서버 로그인                                          │
│    - 세션 쿠키 획득                                            │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 2단계: 요청 (Request)                                          │
│    - 요청 템플릿 로드 (txt 파일)                               │
│    - 쿠키 삽입                                                 │
│    - 날짜 플레이스홀더 치환                                    │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 3단계: 응답 (Response)                                         │
│    - XML 데이터 수신                                           │
│    - lxml로 파싱                                               │
│    - DataFrame 변환                                            │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 4단계: 처리 (Processing)                                       │
│    - 데이터 정제                                               │
│    - 계산 필드 추가 (진척률, 유효유통비, 출하금액 등)          │
│    - 제외 상품 필터링                                          │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 5단계: 저장 (Storage)                                          │
│    - 변화 감지 (SHA256)                                        │
│    - 백업 생성 (변경 시)                                       │
│    - CSV 저장 (UTF-8 BOM)                                      │
└────────────────────────────────────────────────────────────────┘
```

## 🔐 보안 및 인증

### 로그인 프로세스

```mermaid
sequenceDiagram
    participant P as Python 프로그램
    participant O as OSIS 서버
    participant C as 쿠키 저장소
    
    P->>P: login.txt 읽기<br/>(ID, PW)
    P->>O: POST /login<br/>인증 정보 전송
    O-->>P: 200 OK<br/>+ Set-Cookie
    P->>C: 쿠키 저장<br/>JSESSIONID, AWSALB, AWSALBCORS
    
    Note over P,O: 이후 모든 요청에 쿠키 포함
    
    P->>O: POST /data<br/>+ Cookie
    O-->>P: 200 OK<br/>XML 데이터
```

---

### 쿠키 관리

**필수 쿠키 3개:**
1. **JSESSIONID**: 세션 식별자
2. **AWSALB**: AWS 로드 밸런서
3. **AWSALBCORS**: CORS 처리

**쿠키 유효 기간**: 세션 단위 (로그아웃 또는 타임아웃)

### JavaScript 구조 (예정)

```javascript
// ourhome_layout_v5.html에 추가될 코드

// 전역 변수
let updateTimer = null;
const UPDATE_INTERVAL = 30000; // 30초

// 최초 실행
document.addEventListener('DOMContentLoaded', () => {
    console.log('WMS Dashboard 초기화');
    
    // 최초 데이터 로드
    fetchWMSData();
    
    // 자동 갱신 시작
    startAutoRefresh();
});

// 데이터 가져오기
async function fetchWMSData() {
    try {
        const response = await fetch('/api/data');
        const data = await response.json();
        
        console.log('데이터 갱신:', data.timestamp);
        
        // 6개 카드 업데이트
        updateCard2(data.cards.card2_inbound);
        updateCard3(data.cards.card3_outbound);
        updateCard4(data.cards.card4_inventory);
        updateCard5(data.cards.card5_delete);
        updateCard6(data.cards.card6_irregular);
        updateCard7(data.cards.card7_unallocated);
        
    } catch (error) {
        console.error('데이터 로드 실패:', error);
    }
}

// 카드2 업데이트: 입고현황
function updateCard2(data) {
    const card = document.querySelector('#card2');
    
    // 금일 건수
    const countElem = card.querySelector('.today-count');
    countElem.textContent = data.today_count || 0;
    
    // 비교율
    const rateElem = card.querySelector('.comparison-rate');
    rateElem.textContent = data.comparison_rate || '0%';
    
    // 색상 설정
    if (data.comparison_rate.startsWith('+')) {
        rateElem.style.color = 'green';
    } else if (data.comparison_rate.startsWith('-')) {
        rateElem.style.color = 'red';
    } else {
        rateElem.style.color = 'gray';
    }
    
    // 애니메이션 효과
    card.classList.add('updated');
    setTimeout(() => card.classList.remove('updated'), 500);
}

// 자동 갱신 시작
function startAutoRefresh() {
    updateTimer = setInterval(fetchWMSData, UPDATE_INTERVAL);
    console.log('자동 갱신 시작: 30초 주기');
}

// 자동 갱신 중지
function stopAutoRefresh() {
    if (updateTimer) {
        clearInterval(updateTimer);
        updateTimer = null;
        console.log('자동 갱신 중지');
    }
}
```
